# NavigationView 回归记录

## 2026-11-07：阶段 5 的中断、策略与后端切换

- 快速切换透明度策略时，旧 Motion 的 0.01 活动阈值可能让极小的 Acrylic weight 停在非零值。改为按数值精度判断活动，保留最后一帧直至精确 fallback；真实策略往返的调度回归已覆盖。
- React 后端切换曾在创建新 scene 前短暂沿用已销毁的旧 scene。按 backend 重新挂载 SceneRoot，避免旧 controller 提交更新。
- Gallery 仅接受当前动画的结束结果更新 Output，防止旧动画的 Interrupted 通知覆盖新动画的 Running 状态。浏览器验证包含滚轮背景、播放/暂停和真实 pointer 快速反向。

## 2026-11-07：快速往返点击导致指示条异常拉长

- 复现：在几个导航项之间，以动画完成前的速度反复来回点击。
- 原因：中断动画时采样出的指示条已经拉长；下一段动画仍按“当前长度 + 新的移动距离”计算峰值，连续中断会累积长度。
- 修复：从当前画面的两条边界继续动画。前段推进前沿，后段收拢后沿；两条边始终位于当前指示条和目标指示条的包围范围内。保留原生的约 200ms/400ms 两段曲线，重定向时不跳回初始项。
- 验证：Rust 高频重定向、边界与连续性回归，以及真实浏览器中反复 pointer 点击后的几何边界检查。横向、纵向各 5,000 次重定向通过；浏览器 Left/Top 各 70 次真实 pointer 快速点击通过，停止后均恢复 16 DIP。完整测试见 validation.md。


## 2026-11-07：共享投影丢焦点与 GPU 图层反馈

- DOM 投影原先在每帧 append 已存在的容器，会使键盘焦点和 IME 组合状态中断；改为仅在真实子序变化时移动节点，保留组合期间的 textarea 值，并对提交去重。
- GPU 首次/增量挂载和 framebuffer 复用时，sampler 可能仍绑定当前渲染目标，出现 GL_INVALID_OPERATION 1282。形状/stencil 分支显式解绑纹理，恢复后重新创建程序与资源。
- 回归覆盖 Enter/Space、真实 Chromium 中文 composition、React Gallery 后端切换、窗口尺寸变化、设备丢失/恢复；阶段 1–4 完整 21 项浏览器回归通过。


## 2026-11-07：GPU 彩色字形被单色着色

- 单色 mask 路径会把彩色 Emoji 的纹理整体乘以前景色，中文混排中 Emoji 因而变成黑色轮廓；全图平均误差无法充分暴露该局部问题。
- 改为按请求前景色栅格化并缓存 RGBA run，上传后保留原始彩色字形通道；颜色加入缓存键。
- 四档 DPR 对照增加 Emoji 区域彩色像素检查，同时覆盖原始 Gallery 图片按钮，防止只验证几何或平均差分。
